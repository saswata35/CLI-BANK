# CLI Bank

*Command Line Interface - Bank*

## Features

- Create Bank Accounts
- Deposit Amount.
- Withdraw Amount.
- Transfer Amount b/w Accounts.
- Check Balance.
- List all Accounts.
- Stored Account details in a file.
- Store every transactions in a file.
- Logging .

## Code Requirement

- Use OOPs.
- Use JSON.
- Use UUID to get Unique IDs.
- Exception Handling.
- Proper Project Structure.
